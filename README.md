# Neovim configuration

## Requirements

- Neovim `0.12+`
- `tree-sitter` CLI `0.26.1+` available on `PATH` (from your package manager, not npm)
- `tar`, `curl`, and a C compiler available on `PATH` (Tree-sitter parser builds)

## Commands

- To format lua files, run `stylua .`
- On a new machine, run `:TSInstallConfigured`
- After upgrading `nvim-treesitter`, run `:TSUpdate`
